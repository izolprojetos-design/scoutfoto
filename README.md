# ScoutFoto

ScoutFoto is a digital library for scouting organizations, managing media and member photos with Google Drive integration.

This application offers real-time storage monitoring, automatic duplicate archiving, and configurable file cleanup. It supports offline access with local caching and displays connection status. New features include a "Scouting Digital Library" similar to Google Drive, allowing administrators to create, rename, and delete folders. It also supports external linking of photos, videos, and documents with viewing, editing, and deletion options, alongside robust error handling and audit logging.
